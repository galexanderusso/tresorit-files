# Security

If you find a security problem in Tresorit Files, please do not open a public issue.

Report it privately instead: on the page of this project on GitHub, open the "Security" tab and choose
"Report a vulnerability". Only the maintainer sees such a report.

Please say which version you use, what you did and what happened. Reports are answered as time allows.

The connector works on local files only and makes no network connections. A report is especially welcome on
anything that would let it read or change a file outside the Tresorit folder, touch a blocked folder, delete
without the confirmation on the Mac, or send anything anywhere.

Only the latest release is supported.
